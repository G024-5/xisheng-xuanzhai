# 溪声轩斋 · 安装与使用指南（Windows）

> 这份指南写给**完全没配过开发环境**的人。全程只需要装一个软件、点几下鼠标。
> 预计耗时：10 分钟。

---

## 零、先选一种装法

| | 桌面版（省事） | 源码版（照本文档走） |
|---|---|---|
| 要装 Node.js 吗 | **不用** | 要 |
| 启动方式 | 双击图标 | 双击 `start.bat`，再用浏览器 |
| 适合谁 | 只想读书、写笔记 | 想改代码、或系统不是 Windows |
| 数据在哪 | `%APPDATA%\Xisheng\data` | 项目文件夹里的 `data\` |

**选桌面版就别看第二、三、四节了。** 三个文件，从前往后试：

| 文件 | 什么时候用 |
|---|---|
| `XishengXuanzhai-0.6.0-win64.zip` | **推荐**。解压到任意文件夹，双击里面的 `溪声轩斋.exe` |
| `XishengXuanzhai-Setup-0.6.0.exe` | 想装进开始菜单 / 桌面快捷方式 |
| `XishengXuanzhai-Portable-0.6.0.exe` | 拷到 U 盘带走，但每次启动都要自解压，最慢 |

两个可能遇到的提示，都是正常现象：

- **「Windows 已保护你的电脑」** → 点 **更多信息** → **仍要运行**。
  安装包没有买代码签名证书，Windows 对陌生 exe 一律这样提示，不是病毒。
- **「Error writing temporary file. Make sure your temp folder is valid.」**
  → 说明你的 Windows 用户名是中文（比如 `C:\Users\王明瀚\`），安装器在临时目录里建文件失败。
  **直接换 zip 版**，它不经过安装器。实在想用安装版：把 exe 复制到 `C:\Temp\`，再执行

  ```
  cmd /c "set TEMP=C:\Temp&& set TMP=C:\Temp&& start "" C:\Temp\Setup.exe"
  ```

> 不想每次都看到提示：解压后在 PowerShell 里跑 `Get-ChildItem -Recurse . | Unblock-File`，
> 去掉浏览器给文件打的「来自网络」标记。

> 桌面版和源码版的功能、数据格式完全一样。以后从桌面版换回源码版，把
> `%APPDATA%\Xisheng\data` 整个文件夹复制到项目目录下改名 `data` 即可。

下面的第二～四节是**源码版**的安装步骤。

---

## 一、你需要什么

- 一台 Windows 10 或 Windows 11 电脑
- 约 200 MB 空闲磁盘
- 能上网（只有装 Node.js 和下载时需要）

**不需要**：会编程、会命令行、会配置数据库、买服务器。

---

## 二、第一步：安装 Node.js

这是**唯一**需要安装的软件。整个程序靠它运行。

1. 浏览器打开 <https://nodejs.org/zh-cn>
2. 点绿色大按钮下载 **LTS（长期支持版）**，选 **Windows 安装包 (.msi)**
3. 双击下载好的文件，一路点「下一步」，最后点「安装」
   - 安装选项全部保持默认即可，其中「Add to PATH」必须是勾选状态（默认就是）
4. 安装完成后，**验证是否成功**：
   - 按 `Win + R`，输入 `cmd`，回车，会弹出一个黑色窗口
   - 输入 `node -v` 后回车
   - 显示类似 `v22.14.0` 或更高的版本号 → 成功
   - 若显示「不是内部或外部命令」→ 重启电脑再试一次；仍然不行说明没装成功，重新安装一遍

> 建议 Node.js 版本 ≥ 22.5。版本太低会启动失败。

---

## 三、第二步：下载并解压

1. 下载项目压缩包（`xisheng-xuanzhai-vX.X.X.zip`）
2. 找到这个 zip 文件，**右键 → 全部解压缩**
3. 解压到一个**纯英文、不含空格的路径**，例如：

   ```
   D:\Xisheng
   ```

   不要放在桌面、下载文件夹或中文路径下，某些情况下会因权限或编码出错。

4. 打开解压出来的文件夹，应该能看到这些内容：

   ```
   Xisheng\
   ├─ start.bat      ← 启动用
   ├─ doctor.bat     ← 出问题时自检用
   ├─ src\
   ├─ public\
   └─ README.md
   ```

> ⚠️ 不要在压缩包的预览窗口里直接双击 `start.bat`，必须先解压。

---

## 四、第三步：启动

1. 双击 **`start.bat`**
2. 会弹出一个黑色命令行窗口，显示类似：

   ```
   Xisheng Xuanzhai - starting
   Folder: D:\Xisheng
   Node: v22.14.0

   溪声轩斋 · http://127.0.0.1:5178
   数据目录 D:\Xisheng\data
   ```

3. 几秒后浏览器会**自动打开** <http://127.0.0.1:5178>
4. 看到「分类 / 文献列表 / 阅读区」三栏界面，就成功了

**关于那个黑色窗口：**

- 它就是程序本体，**关掉窗口 = 关闭程序**，网页立刻打不开
- 用的时候把它缩到后台即可，不用管它
- 下次使用：再双击一次 `start.bat`

## 五、第一次使用

### 添加第一篇文献

1. 点左上角列表标题旁的 **＋**，或直接把 PDF **拖进窗口**
2. 选择 PDF 文件
3. 程序会自动识别标题和作者，**请核对**，不对就直接改
4. 点「添加到文库」

也可以粘贴 DOI 或 arXiv 号（如 `2301.12345`）自动抓取，arXiv 还会顺带下载 PDF。

### 阅读与笔记

- 中间列表点一篇文献，右侧显示 PDF
- 在 PDF 里**选中文字**，会浮出四色高亮按钮，点一下就标好了
- 选中的文字还可以点「译」当场翻译，点「引」把原文和译文一起写进笔记
- 右下角「笔记」栏可以直接写，自动保存
- 顶部「侧栏 / 列表 / 信息」三个按钮可以收起对应面板，PDF 会跟着变大

### 四个常用小功能

- **查找**：在 PDF 里按 `Ctrl+F`，输入关键词，回车跳下一条，`Esc` 关闭
- **继续读**：关掉再打开会自动回到上次那一页；顶栏会提示「上次读到第 N 页」
- **夜间模式**：点顶栏的月亮/太阳图标；也可以在 ⚙ 里选
- **引文**：详情页顶部「引文」→ 选 BibTeX / GB/T 7714 / RIS → 复制

### 文献拼图

点顶部「拼图」：

1. 「＋ 拼图」新建一张画布
2. 「＋ 文献卡」添加一张卡，在右侧选文献、写「问题 / 方案 / 局限」
3. 拖动卡片摆位置；点卡片右下角小圆点，再点另一张卡，就能连线
4. 可以给卡片选颜色、归入支链

## 六、可选：接入 AI（摘要与翻译）

不配置也能正常用，只是没有「AI 摘要」和「译」按钮。两条路，任选一条。

### 路线 A：云端，几分钟搞定（推荐新手）

1. 打开 <https://platform.deepseek.com> 注册并登录
2. 左侧「API Keys」→ 创建，复制那串 `sk-` 开头的密钥
3. 回到应用，点右上角 **⚙**，服务预设选「DeepSeek」
4. 粘贴密钥 → 点「测试连接」→ 显示正常后点「保存」

成本：每篇论文约 ¥0.02（读全文生成四段摘要）。
不想花钱的话，预设里选「硅基流动」，注册送额度，模型填 `Qwen/Qwen2.5-7B-Instruct`。

### 路线 B：本机免费（不联网、不花钱，但慢）

1. 打开 <https://ollama.com/download> 下载 Windows 版并安装
2. 打开「命令提示符」，运行 `ollama pull qwen2.5:7b-instruct-q4_K_M`（约 4.7 GB，一次就好；
   显存或内存紧张就换 `qwen2.5:3b`，约 2 GB）
3. **关键一步**：Ollama 默认只给 4k 上下文，长篇论文会被截断到中段，模型就开始瞎编。
   在仓库根目录执行下面两条，做一个上下文 16k 的包装模型：

   ```
   ollama create xisheng-qwen:7b -f scripts/ollama/Modelfile
   ```

   （用 3b 的话，先把 `scripts/ollama/Modelfile` 第一行的 `FROM` 改成 `qwen2.5:3b`，
   名字也换成 `xisheng-qwen:3b`）
4. 回到应用 ⚙，服务预设选「Ollama 本机」，模型填 `xisheng-qwen:7b`
5. **Key 留空**，点「测试连接」→ 显示正常后点保存

实测（RTX 3050 Laptop 4 GB 显存 + 7B Q4）：一篇摘要 12–25 秒；
纯 CPU 会到 1–3 分钟。它读的是正文前 8000 字，够抓住问题、方法、结论，
但不如云端模型细。想让本机模型读更多：

```
set OLLAMA_CONTEXT_LENGTH=32768
set XISHENG_AI_MAXCHARS=24000
```

（第一条给 Ollama 调上下文，第二条给应用调送进去的字数上限；改完要先关掉、重新打开这两个程序）

密钥只保存在你自己电脑的 `data\app.db` 里，不会上传到别处。

## 七、数据在哪、怎么备份

所有数据都在一个 `data` 文件夹里：

```
data\
├─ app.db          数据库（文献信息、笔记、标注）
├─ storage\        PDF 原文
└─ backups\        自动备份（每天一份，保留 10 份）
```

位置取决于装法：

- **源码版**：项目目录下的 `data\`
- **桌面版**：`C:\Users\<你的用户名>\AppData\Roaming\Xisheng\data`
  （在文件管理器地址栏粘贴 `%APPDATA%\Xisheng\data` 就能打开）

**备份**：把整个 `data` 文件夹复制到别处即可（U 盘、网盘）。

**换电脑**：源码版装好 Node.js 后拷整个项目文件夹；桌面版拷 `data` 文件夹到新机器的同一位置。

**恢复**：用备份的 `data` 文件夹覆盖回去。

## 八、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 `start.bat` 窗口一闪就没了 | 缺 Node.js 或文件不完整 | 窗口会停留提示，看清红字；仍不行跑 `doctor.bat` |
| 网页显示「无法访问此网站」 | 服务没起来，或浏览器开得太早 | 看黑色窗口里有没有报错；重新双击 `start.bat` |
| 提示 `EADDRINUSE` / 端口被占用 | 已经开着一个实例 | 现在会自动往后找空端口（5179–5188）；想固定：`set PORT=5179` |
| 桌面版双击后弹「已保护你的电脑」 | 安装包没有代码签名 | 点「更多信息 → 仍要运行」 |
| 桌面版双击没反应 | 上一次没退干净，或安装目录被拦 | 任务管理器结束「溪声轩斋」再开；仍不行重装 |
| `node` 不是内部或外部命令 | Node.js 没装好或没加进 PATH | 重装 Node.js，勾选 Add to PATH，然后重启 |
| 浏览器打开是空白页 | 浏览器太旧 | 用 Edge 或 Chrome 最新版 |
| 杀毒软件报警 | 本地服务被误判 | 选择「允许」；程序不联网上传任何数据 |
| PDF 显示不出来 | 文件损坏或加密 | 换一个 PDF 试试 |
| 中文路径下启动报错 | 路径编码问题 | 把文件夹移到 `D:\Xisheng` 这类纯英文路径 |

### 看不懂报错时

双击 **`doctor.bat`**，它会列出：Node 版本、关键文件是否齐全、数据目录能否写入、数据库状态、端口占用情况。

把整屏内容截图发给开发者即可定位。

## 九、常见问题

**Q：能不能不装 Node.js？**
A：暂时不能。它是运行环境，就像看视频要装播放器。

**Q：能多台电脑同步吗？**
A：这一版是单机版，数据只在本机。需要同步得自己用网盘同步 `data` 文件夹（同时只能开一台，否则会冲突）。

**Q：能给别人用吗？**
A：这只是本地程序，只有你这台电脑能访问。想共享需要额外的服务器部署，不在本指南范围。

**Q：手机能用吗？**
A：不能，页面只监听本机地址。

**Q：怎么卸载？**
A：直接删掉整个项目文件夹。Node.js 如果不想留，去「设置 → 应用」里卸载。

**Q：数据会不会丢？**
A：程序每天自动备份到 `data\backups`，保留 10 份。但删除操作不可撤销，重要内容请另外备份。
